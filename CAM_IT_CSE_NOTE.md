## Why do we need Object-Oriented Programming?

**_Software is Becomming More Complex_**
- Modern systems contain
- Thiusands of functins
- Milions of lines of code
- Multiple developers working togather

**_Example:_**
- ERP System (Enterprise Resource Planning: is software that acts as the central nervous system for business.)
- Banking Systems
- E-Commerce Platforms
- Social Media Applications

**_Problem_**
- As software grows, maintaining procedural code becomes difficult.

## Limitatins of Procedural Programming
### Procedural Programming
**_Focuses on:_**
- Functions
- Procedures
- Sequential execution

**_Challenges_**
- Data and functions are seperate
- Difficult maintenance
- Code duplication
- Poor scalability
- Hard to collaborate in large projects
